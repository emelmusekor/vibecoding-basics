# 바이브코딩 기초: 파일 한 장의 여행

바이브코딩 연수 사전 학습 페이지. 비전공자가 혼자 읽고 컴퓨터 기초(파일, 폴더, 경로, 로딩, 클라우드, 배포, 서버, 호출, API 키, 터미널, 오류, 되돌리기)를 익히도록 만든 한 페이지 사이트입니다.

- 주소: https://emelmusekor.github.io/vibecoding-basics/
- 구조: `chapters/chNN.html|js|css` 를 `build.py` 가 `template.html` 에 끼워 `index.html` 을 만듭니다.
- 고친 뒤: `python build.py` → 커밋·푸시하면 GitHub Pages 에 반영됩니다.
