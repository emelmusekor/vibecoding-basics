코드도 서류일 뿐

비유 서류를 읽어 주는 사람 · 용어 코드, HTML, 자바스크립트, 파이썬

바이브코딩을 하면 AI가 index.html, app.js, 정리하기.py 같은 파일을 만들어 줍니다. 이런 파일 안에 적힌 글을 코드라고 합니다. 코드 파일도 다른 서류와 똑같이 글자가 적힌 서류 한 장입니다. 메모장으로 열면 그냥 글자가 보입니다. 무섭게 볼 필요가 없습니다.

다만 코드는 혼자서는 아무 일도 하지 않습니다. 그 서류를 읽고 적힌 대로 해 주는 사람이 있어야 합니다. 웹페이지 서류는 크롬 같은 브라우저가 읽고, 파이썬 서류는 파이썬이라는 프로그램이 읽습니다. 코드를 직접 쓸 줄 몰라도 됩니다. 어떤 서류가 무슨 일을 하는지 알아보기만 하면 충분합니다.

.html · 화면의 뼈대제목은 여기, 글은 여기, 버튼은 여기처럼 화면에 무엇이 어디에 있는지 적은 서류입니다. 브라우저가 읽습니다.
.js · 화면 속 움직임자바스크립트 서류입니다. 버튼을 누르면 글자가 바뀌는 것처럼 화면이 반응하게 합니다. 이것도 브라우저가 읽습니다.
.py · 컴퓨터 안의 조수 일파이썬 서류입니다. 파일 이름 100개 바꾸기, 엑셀 숫자 계산처럼 화면 밖에서 하는 일을 적습니다. 파이썬이 읽습니다.

가끔 .css 파일도 보입니다. 글자색, 크기, 버튼 모양처럼 화면을 꾸미는 서류이고 브라우저가 읽습니다.

파이썬 조수에게 이름 바꾸기 시키기

운동회 사진 이름이 IMG_0001.jpg처럼 되어 있습니다. 실행을 누르면 파이썬이 왼쪽 서류를 읽고 이름을 차례로 바꿉니다.

이름바꾸기.py
import os
# 운동회 폴더의 사진 이름을 차례로 바꿉니다
files = sorted(os.listdir("운동회"))
for i, name in enumerate(files, start=1):
    os.rename(f"운동회/{name}", f"운동회/운동회_{i:03d}.jpg")
파이썬이 이 서류를 읽습니다

    코드 파일을 더블클릭했더니 글자만 잔뜩 나와요.
    그 서류를 메모장이나 편집기가 열었기 때문입니다. 편집기는 서류를 읽어 주는 사람이 아니라 글자를 보여 주고 고치게 해 주는 프로그램입니다. 화면으로 보려면 .html 파일을 크롬으로 열어야 합니다.
    .py 파일을 더블클릭하면 까만 창이 떴다가 바로 사라져요.
    파이썬이 서류에 적힌 일을 다 하고 창을 닫은 경우가 많습니다. 일이 금방 끝나면 결과를 볼 틈도 없이 닫힙니다. 중간에 문제가 생겨 멈춘 경우에도 창이 바로 사라집니다. 컴퓨터에 파이썬이 아예 없으면 까만 창 대신 "이 파일을 어떻게 여시겠습니까?" 창이 뜹니다. 이럴 때는 AI에게 "어떻게 실행하면 결과를 볼 수 있느냐"고 물어보면 됩니다.
    .html 파일이 메모장으로 열려요.
    그 양식을 맡을 프로그램(연결 프로그램)이 메모장으로 정해져 있는 경우입니다. 파일을 마우스 오른쪽 단추로 누르고 연결 프로그램 → Google Chrome을 고르면 크롬으로 열립니다.

    코드 = 글자로 적힌 서류. .html은 화면의 뼈대, .js는 화면 속 움직임으로 브라우저가 읽고, .py는 조수 일로 파이썬이 읽습니다.
